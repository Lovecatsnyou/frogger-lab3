Классическая аркадная игра **Frogger**, реализованная на Python с использованием стандартной библиотеки `tkinter` и объектно-ориентированного подхода (ООП). Не требует установки сторонних зависимостей.

## Особенности реализации

- **Динамическая генерация трафика:** вместо заскриптованных циклов каждая полоса (`Lane`) самостоятельно генерирует случайный поток машин и бревен разных типов и размеров с расчетом безопасных интервалов.
- **Прогрессия сложности:** каждый успешный проход до финиша повышает уровень и ускоряет движение на всех полосах на **+15%**.
- **Таймер на попытку:** на каждый проход дается 25 секунд с визуальной индикацией (зеленый → желтый → красный). За оставшееся время начисляются бонусные очки.
- **Бонусные мухи:** периодически появляются на карте, дают **+50 очков** и **+5 секунд** к таймеру.
- **Счетчик рекорда:** отслеживает лучший результат в рамках игровой сессии.

## Управление

Управление работает на любой раскладке (EN / RU):

| Действие | Клавиши |
| --- | --- |
| Вверх | `↑` / `W` / `Ц` |
| Вниз | `↓` / `S` / `Ы` |
| Влево | `←` / `A` / `Ф` |
| Вправо | `→` / `D` / `В` |
| Рестарт | `Пробел` |

## Архитектура проекта

Весь код построен на иерархии классов:

- `GameObject` — базовый класс для всех сущностей на холсте (отрисовка, перемещение, проверка AABB-коллизий `intersects`).
- `Frog` — класс игрока с дискретным перемещением по сетке (шаг 40 px) и переносом скорости при нахождении на бревне.
- `Obstacle` — движущийся объект (автомобиль или бревно).
- `BonusFly` — временный бонусный объект с таймером жизни (`ttl`).
- `Lane` — контроллер полосы, отвечающий за случайный спавн, движение и удаление объектов за границами экрана.
- `FroggerGame` — главный игровой контроллер (игровой цикл, HUD, таймер, обработка коллизий и уровней).
