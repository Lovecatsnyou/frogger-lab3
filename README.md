## Описание проекта

Программа представляет собой классическую 2D-аркаду **Frogger**, реализованную на Python с использованием стандартной библиотеки `tkinter` и объектно-ориентированного подхода (ООП). Игроку необходимо провести лягушку через оживленную дорогу с динамическим трафиком и реку с движущимися бревнами до финишной зоны, укладываясь в отведенное время. Каждый успешный переход повышает уровень и ускоряет игровой процесс.

## Функциональные возможности

### Основной функционал
- 🐸 Дискретное перемещение игрока по игровой сетке (шаг 40 px) с проверкой границ экрана
- 🚗 Динамическая генерация трафика: случайные типы машин и бревен с расчетом безопасных интервалов
- 🪵 Механика переправы по реке: автоматический дрейф игрока вместе с движущимся бревном
- 💥 Обработка столкновений (AABB-коллизии) с автомобилями, падением в воду и выходом за края экрана
- ❤️ Система жизней (3 попытки) и подсчет игровых очков

### Дополнительный функционал
- ⏱️ Таймер обратного отсчета (25 секунд на попытку) с цветовой индикацией (зеленый → желтый → красный) и бонусом за оставшееся время
- 📈 Прогрессия сложности: ускорение всех полос на +15% с каждым новым уровнем
- 🪰 Бонусные мухи: периодически появляются на карте, дают +50 очков и +5 секунд к таймеру
- 🏆 Счетчик рекорда в рамках текущей сессии
- ⌨️ Поддержка управления на английской и русской раскладках (стрелки, WASD / ЦФЫВ), быстрый рестарт по `Пробелу`

## Структура проекта

```text
frogger/
├── Frogger.py
└── README.md
```

**Назначение основных компонентов в `Frogger.py`:**
- `GameObject` — базовый класс для всех сущностей на холсте (отрисовка, перемещение, проверка AABB-коллизий `intersects`).
- `Frog` — класс игрока, отвечающий за прыжки по сетке и возврат на стартовую позицию.
- `Obstacle` — класс движущегося препятствия (автомобиль на дороге или бревно на реке).
- `BonusFly` — временный бонусный объект с таймером исчезновения (`ttl`).
- `Lane` — контроллер полосы движения, отвечающий за случайный спавн, скорость, направление и удаление объектов за границами окна.
- `FroggerGame` — главный контроллер игры (игровой цикл, отрисовка карты, HUD, таймер, обработка коллизий и смена уровней).

## Пример использования

### Запуск программы
```bash
python3 Frogger.py
```

После запуска откроется графическое окно игры `600×560` с уже заполненными полосами движения. В верхней панели отображаются текущий уровень, счет, рекорд, количество жизней и полоска таймера. Используйте стрелки или `WASD` (`ЦФЫВ`), чтобы пересечь дорогу и реку до истечения времени; после окончания жизней нажмите `Пробел` для начала новой партии.
